# Figure 2 methods and implementation

This package reproduces the selected surrounding-cortex training run and the
five-panel figure. Experimental geometry, RF boundary and prototypes are supplied inputs. V1 fitting
and downstream analysis can be regenerated; archived arrays support the separate
exact rendering path.

## Model and loss

The cortical grid has 160 periodic positions around V1 and 16 trainable columns
extending outward: 2,560 receptive-field (RF) positions, each with azimuth and
elevation coordinates. The supplied surface has one additional inner boundary
column. The RF boundary is prescribed separately and shared by the V1 and
surrounding-cortex fits; it is not generated by the matched V1 fit.

`seeded_initial` uses NumPy `RandomState(2026111604)` to sample 2,560 entries
with replacement from the 2,000 fixed visual-field prototypes, then adds
independent Gaussian noise with standard deviation 1 degree in each coordinate.

The loss is `coverage + b1 * smoothness + b2 * boundary + b3 * isotropy`, with
`b1=1.45e-5`, `b2=100`, and `b3=0.03`:

- **Coverage:** `-kappa * sum_x log(sum_i exp(-||y_i-x||²/(2*kappa²)))`,
  evaluated using stable log-sum-exp. All prototypes participate in every update.
- **Smoothness:** squared RF differences between immediate axial and diagonal
  cortical neighbors, weighted by inverse squared cortical distance. Both edge
  directions are retained. The grid wraps around V1 and is open across columns.
- **Boundary agreement:** squared RF differences linking the innermost learned
  column to the fixed RF boundary, using `make_boundary_mask`.
- **Local isotropy:** a weighted least-squares local Jacobian gives `G = J Jᵀ`.
  The node contribution is `((G00-G11)² + 4*G01²) / ((G00+G11)² + epsilon)`.
  The GPU stencil preserves the derivative operator's diagonal coefficients and
  reduction order. This term penalizes unequal local stretch, not field-sign
  reversals directly.

## Optimization and exactness

The selected run uses TensorFlow 2.17.1 in v1 compatibility mode and float64
arrays. RMSProp starts at learning rate 0.1 with momentum 0.8. At optimizer
step `t`, the learning rate is `0.1 * eta_decay**(t/10)` with
`eta_decay=0.9933221725495059`; the decay is continuous, not staircase.
Kappa begins at 44 and is multiplied by `1-0.001533921712758013` after each
update. Training performs 3,000 updates and saves checkpoints every 25 updates.
The model, optimizer slots and step counter are reset before training.

The initialization and checkpoints at updates 2500 and 3000 must match the
archive. GPU numerical differences can prevent exact replay even with the same
seed. CPU smoke checks establish that the extracted code runs, not GPU parity.

## From the learned map to the figure

`data/figure2_data.npz` includes the selected endpoint, matched V1 fit, cortical
coordinates, parcel labels, injection memberships and dense display arrays.
`data/panel_B_partition_field.npz` contains the native field-sign map corresponding
to those parcels. `data/figure2_shared_model.json` records the preparation recipe
and historical provenance; the panel scripts define the final display styling.

`build_figure_data.py` regenerates these arrays from archived or newly trained
endpoints. Segmentation normalizes the HVA RF extent to 80 by 50 degrees and
uses the explicit selected parameters in the metadata, including native
field-sign smoothing of 0.1 mm. Dense V1 display field-sign smoothing is 0.075 mm.
The recorded parameters define the selected segmentation. The sign of each parcel
is saved as `parcel_signs` in the metadata; panel D assigns colors from those
signs rather than assuming a particular parcel count or order.

Injection mapping inverts the piecewise-linear V1 triangles, retaining all
preimages. A target belongs to an injection when any preimage lies inside its
prescribed cortical disk (radius 0.19 mm). Registration excludes distinct
ambiguous inverses and forward-checks the remaining points. It anchors the
inner border exactly, fills outer-edge gaps periodically, and interpolates
remaining gaps across the strip. A saved mask identifies interpolated points.

Panel C height follows shortest cortical distance from the inner border, with
scale 0.26 times the V1 span and offset 0.30 times that span. Light Gaussian
smoothing affects registered XY only, with sigma 3 samples around and 1.5 across;
the inner border is restored exactly. This illustrative surface is not
independent evidence for reversals. Quantitative fields use the unsmoothed fit.

The CPU V1 model uses the same loss coefficients and optimizer schedule, but
its 1,521 trainable nodes have nonperiodic eight-neighbor adjacency and
unit-weight links to a fixed 160-point RF perimeter. Harmonic geometry extends
the original cortical perimeter to the interior. This differs in discretization
from HVA; identical coefficients do not make the objectives equal in scale.
The exact original V1 boundary samples are necessary for the validated replay.

`reproduce.py` keeps using frozen downstream arrays and exact output hashes.
`build_figure_data.py` records numerical comparisons for regenerated methods.
